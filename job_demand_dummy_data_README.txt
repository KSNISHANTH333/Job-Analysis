Job Demand and Sector Analytics — Synthetic Demo Dataset

Coverage: 2023, 2024, 2025; Karnataka; five sample districts; seven sectors.
Records: 1575
Every row is synthetic and is intended only for software testing and demonstration.
It is NOT real government data and must not be used to make factual claims about employment.

Columns:
- reporting_period: reporting year (2023–2025)
- state: state label (Karnataka)
- district: sample district label
- sector: synthetic economic sector category
- occupation: synthetic occupation category
- indicator_type: Observed Job Postings (simulated), Simulated Vacancy Count, or Employment Estimate
- value: generated numeric value
- unit: measurement unit; do not combine unlike units or indicators
- source_name: Synthetic Test Dataset
- is_synthetic: True for every row

Important:
Although indicator labels describe different kinds of measures, all values in this file are synthetic.
The vacancy and employment values are not observations from a real source. The 'Observed Job Postings'
label is included only to test dashboard categorisation; these are simulated posting counts, not real postings.
Keep this dataset clearly labelled as synthetic in every dashboard view and chart.
